Speed Typing Game - A game based on speed typing, with points, you could buy colors, animations, and upgrades to fully customize the UI to your liking.
The more faster you type, more points you get, but make sure it's wrote correctly!
Full beautiful shop.
You can reset you're progress.
Full config system. (Encrypted configuration file with Base64)
Promo code system.
Promocode list: "Summer" - Code which gives you 50 points, because it is summer time 2026!!
"Free" - Code which gives 100 points, very helpful.
"Admin" - Code which gives you the admin panel, you can turn on speed hacks, customize your points, and unlock everything with a single click!

!THE GAME CAN BE INSTALLED WITHOUT OPENING SOURCE CODE. THE GAME IS INSTALLABLE IN RELEASES!

[Requirements: Python 3.12 https://www.python.org/downloads/release/python-3120/]
[Requirements: pygame (open command prompt and write "py -3.12 -m pip install pygame"]
[Now you're all set, all you need is run the file "start.bat"]
[If you want to open throught a command prompt, you could with completing these steps:
Open command prompt
type "cd blank" and instead of blank, write the path to the folder where the source code of the game is.
after that write "py -3.12 tetriz.py"
the game will open, and enjoy]
