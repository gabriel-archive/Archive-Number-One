PS 5 Controller Tester, a script made for fun, which debugs numbers of playstation controllor buttons, which you can use for you're games to add PS 5 Controller support.
[Requirements: Python 3.12 https://www.python.org/downloads/release/python-3120/]
[Requirements: pygame (open command prompt and write "py -3.12 -m pip install pygame"]
[Now you're all set, all you need is run the file "ps5.bat"]
[If you want to open throught a command prompt, you could with completing these steps:
1. Open command prompt
2. type "cd blank" and instead of blank, write the path to the folder where the source code of the game is.
3. after that write "py -3.12 main.py"
4. the app will open, and enjoy!]
