PS 5 Controller Tester, a script made for fun, which debugs numbers of playstation controllor buttons, which you can use for you're games to add PS 5 Controller support.
----
PS5 Controller Tester — это скрипт, созданный ради развлечения, который отображает номера кнопок и осей контроллера PlayStation. Эти значения можно использовать, чтобы добавить поддержку контроллера PS5 в свои игры.
